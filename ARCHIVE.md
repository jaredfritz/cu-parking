# ARCHIVE.md — cu-parking

This repository is archived as of April 2026 and is read-only.

## What this was

An earlier iteration of the CU Parking platform built under `~/cu-parking`. A demo version was live on `cuparking.com` via Vercel. The project is on pause while a new, more focused MVP build is underway.

## Where the active project lives

The new project is in the `cuparking` repository (note: no hyphen). It targets the same domain (`cuparking.com`) and covers the same core product but with a tighter MVP scope aimed at winning the Champaign/Urbana/UIUC RFP.

## Status of this repo

- The Vercel deployment remains live at its `.vercel.app` URL for reference
- `cuparking.com` has been reassigned to the new project
- No further commits will be made here unless the project is revived

## To revive

Unarchive the repo on GitHub (Settings → Unarchive), reconnect the Vercel project to a subdomain or staging domain, and review the new project's `mvp-plan.md` to understand what has changed in scope.
